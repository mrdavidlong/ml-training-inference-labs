# Glossary

- **API — Application Programming Interface:** a contract used by programs to
  communicate.
- **APC — Automatic Prefix Caching:** reuse of cached computation for shared
  prompt prefixes.
- **CUDA — Compute Unified Device Architecture:** NVIDIA's accelerator
  programming and software platform.
- **GPU — Graphics Processing Unit:** a parallel processor well suited to large
  matrix operations.
- **Gradient:** the direction and rate at which loss changes as a parameter
  changes.
- **Hyperparameter:** a practitioner-chosen training setting rather than a
  value learned from examples.
- **HTTP — Hypertext Transfer Protocol:** the network protocol used by the
  serving API.
- **ITL — Inter-Token Latency:** time between generated tokens.
- **JIT — Just-In-Time compilation:** compiling a computation when its needed
  shapes and types become known.
- **KV cache — Key-Value cache:** stored attention keys and values from earlier
  tokens.
- **LLM — Large Language Model:** a model trained to process and generate
  language tokens.
- **LoRA — Low-Rank Adaptation:** a method that freezes a base model and trains
  small low-rank update matrices.
- **MPS — Metal Performance Shaders:** Apple's framework used by PyTorch to
  accelerate operations on Apple GPUs.
- **MSE — Mean Squared Error:** the average squared difference between numeric
  predictions and targets.
- **MLX:** Apple's array and machine-learning framework for Apple Silicon.
- **p50/p95/p99:** latency percentiles showing median and tail behavior.
- **Prefill:** processing input tokens before the first output token.
- **PEFT — Parameter-Efficient Fine-Tuning:** methods that adapt a model by
  training a small portion of parameters.
- **Policy:** an agent's rule for choosing an action in a state.
- **Q-value:** an estimate of future reward for an action in a state.
- **Quantization:** representing numbers with lower precision or fewer bits.
- **RL — Reinforcement Learning:** learning behavior through actions and
  rewards from an environment.
- **RMSE — Root Mean Squared Error:** the square root of MSE, expressed in the
  target's original units.
- **SLA — Service-Level Agreement:** an external commitment, often contractual.
- **SLI — Service-Level Indicator:** a measured reliability or performance
  quantity.
- **SLO — Service-Level Objective:** a target for an SLI.
- **TTFT — Time to First Token:** delay from request start until the first
  generated token arrives.
- **XLA — Accelerated Linear Algebra:** a compiler used by JAX and other systems
  for numerical computation.
